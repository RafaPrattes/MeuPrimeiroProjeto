## 📚🎬 Sistema de Recomendação de Livros e Filmes — Java
Sistema de recomendação simples e funcional, desenvolvido em Java, que ajuda usuários a descobrirem livros e filmes com base em seus gêneros favoritos.

## 📊 Status do Projeto
🚧 Em desenvolvimento
A versão atual está funcional com a lógica principal de recomendação.
Futuras melhorias estão em andamento para adicionar interatividade, avaliações e sistema de busca.

## 🧠 Como funciona?
O usuário informa:

Seus gêneros favoritos (ação, comédia, romance, ficção científica etc.);

Se deseja recomendações de livros ou filmes.

O sistema:

Filtra uma lista pré-definida;

Retorna sugestões personalizadas.

## 🛠 Tecnologias e Estrutura
Java (console application)

Programação Orientada a Objetos (POO)

Uso de listas, classes e condicionais

Estrutura simples e clara para manipular dados de títulos

🚀 Melhorias planejadas
💬 Sistema de avaliações e comentários

🔍 Busca por palavra-chave ou nome

📚 Catálogo mais amplo e categorizado

## ✨ Objetivos do Projeto
Aplicar conceitos de POO e lógica de programação em Java, desenvolvendo uma solução simples, útil e personalizada para os usuários.
